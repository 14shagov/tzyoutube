# Тестовое задание: копия YouTube

## Контекст

Команда работает так: код пишут ИИ-инструменты (Claude, Cursor, ChatGPT), а инженер — архитектор, ревьюер и постановщик задач.

Задание проверяет:

- архитектурное мышление: цель → решения и собственные критерии «что значит работает правильно»;
- проектирование системы в целом: данные, хранилище, безопасность, эксплуатация;
- работу с объектным хранилищем;
- автотесты критичного поведения;
- навыки настройки ИИ в разработке: промпты, декомпозиция, проверка результатов.

**Срок выполнения:** 10 дней с момента получения.

---

## Задание

Через ИИ создать копию YouTube — насколько получится.

YouTube — сервис, который знают и которым пользуются все: не нужно читать требования и разбираться, что должно работать — это и так известно.

### Экраны

1. **Главная** — лента видео с превью.
2. **Просмотр видео** — плеер, лайки, комментарии.
3. **Канал** — видео и плейлисты автора, подписка.
4. **Поиск** — по названию.
5. **Загрузка** — выбор файла, прогресс, метаданные.
6. **Вход и регистрация.**
7. **Модерация** — жалобы и скрытие видео.

### Требования к начинке

- Загрузка, хранение и раздача видео — сердце системы.
- Роли: пользователь, модератор, администратор.
- Приватные видео — только тем, кому разрешил владелец.

### Фиксировано

- Python + FastAPI, PostgreSQL.
- Swagger (`/docs`).
- Экраны — простой фронт.
- Весь код — через ИИ, промпты сдаются вместе с кодом.
- Деплой на чистой Ubuntu **одной командой**.

## Что сдать

Результат — **zip-файл**, внутри которого:

### 1. Код

- Front-end, back-end, инфраструктура — как git-репозиторий целиком, **вместе с каталогом `.git` и всеми коммитами**.
- По истории коммитов проверяющие смотрят, как кандидат работает с git.
- **Не чистить историю и не склеивать всё в один коммит.**

### 2. Файлы диалогов с ИИ

- Использованные для создания проекта.
- **Строго в исходном формате, который генерирует сам инструмент.**
- Без пересказов, копипасты и скриншотов.
- Нужны только диалоги, использованные для решения этого задания; остальные переписки не нужны и не запрашиваются.

Где брать диалоги по инструментам:

| Инструмент | Откуда брать диалоги |
|---|---|
| Cursor | Cursor Settings → Chats → Export all chat data; в архив положить чаты, относящиеся к проекту |
| Claude Code | Файлы сессий из `~/.claude/projects/<проект>/` — это ровно диалоги этого проекта; скопировать в архив все `*.jsonl` целиком |
| ChatGPT и Claude (веб) | Экспорт данных: Settings → Data controls → Export data; приложить диалоги, относящиеся к заданию |
| Другие инструменты | Аналоги (файлы истории, которые создаёт сам инструмент) |

### 3. Агентная обвязка

Все файлы, которыми настраивался ИИ, **как есть, без чистки**:

| Инструмент | Что приложить |
|---|---|
| Cursor | `AGENTS.md` в корне проекта и каталог `.cursor/`: `rules/`, `skills/`, `commands/`, `mcp.json` |
| Claude Code | `CLAUDE.md`, каталог `.claude/`: `agents/`, `skills/`, `commands/`, `settings.json`, плюс `.mcp.json` из корня проекта |
| Другие инструменты | Аналоги: файлы правил, скиллов, агентов и подключений MCP |

> Ключевое для проверяющих — получить именно диалоги по этой задаче и обвязку в исходном виде: по ним видно, как кандидат мыслит и работает с ИИ. Код без них — половина результата.

## Как проверяют

Систему разворачивают на чистой виртуальной машине для тестирования и проверяют:

1. **Объём** — сколько успел сделать.
2. **Соответствие оригиналу** — насколько копия похожа на YouTube: дизайн, расположение элементов и так далее.
3. **Разворачиваемость** — всё разворачивается на чистой Ubuntu одной командой: приложение, БД, хранилище, фоновая обработка.
   - После развёртывания сразу работает сценарий: **регистрация → загрузка → просмотр → лайк и комментарий**.
   - В архиве должны быть: README, `docs/`, автотесты и скрипт наполнения базы демо-данными (пользователи, видео, комментарии), чтобы систему можно было проверить целиком.
4. **Архитектура** — какая архитектура придумана и применена для этого приложения.
5. **Проектирование БД** — схема, связи, что и где хранится.
6. **ИИ и обвязка** — как настроены искусственный интеллект и агентная обвязка.
7. **Безопасность** — насколько всё защищено с точки зрения ИБ.
8. **Git** — осмысленная история коммитов.
